# Charybdis Battery — System Tray Monitor

Кроссплатформенная утилита на Rust для Windows и Linux, которая сидит в системном трее, показывает заряд левой и правой половин Charybdis Mini и отправляет системные уведомления при низком заряде.

## Как работает
- Опрашивает клавиатуру (по проводу `0x4C4B:0x4643` или через USB-донгл `0x4C4B:0x4644`) по Vial HID-команде `[0x53, 0x04]`.
- На донгле данные берутся из локального кэша (без лишних BLE-запросов и задержек для трекбола).
- Иконка в трее динамически рисует 2 полоски заряда (слева — левая половина, справа — правая):
  - **Зелёный**: ≥ 40%
  - **Жёлтый**: 20%–39%
  - **Красный**: < 20%
  - **Синий**: идёт зарядка
  - **Серый**: не подключена / нет связи
- При падении заряда ниже порога (по умолчанию **20%**, критический **10%**) отправляет системное уведомление (с защитой от спама).

## Готовые бинарники
- Windows: `bin/charybdis-battery.exe`
- Linux: `bin/charybdis-battery`

## Параметры запуска
```bash
charybdis-battery [--threshold 20] [--poll-secs 5] [--once]
```
- `--threshold <N>` — порог уведомления о низком заряде в % (по умолчанию `20`, также можно менять в меню трея).
- `--poll-secs <N>` — интервал опроса в секундах (по умолчанию `5`).
- `--once` — однократно вывести статус в консоль и выйти.

## Сборка из исходников
Из директории `tools/charybdis-battery` (нужно указывать `--target`, чтобы не подхватывался `thumbv7em-none-eabihf` из корневого `.cargo/config.toml`):
```bash
# Linux (Ubuntu, без внешних C-зависимостей)
cargo build --release --target x86_64-unknown-linux-gnu

# Windows (из Windows или кросс-компиляция из WSL с mingw-w64)
cargo build --release --target x86_64-pc-windows-gnu
```
